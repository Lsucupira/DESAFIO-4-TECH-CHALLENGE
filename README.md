A solução integra Databricks, PySpark, Embeddings, Bancos Vetoriais (ChromaDB e LanceDB) e Meta Llama 3.1, permitindo responder perguntas em linguagem natural com base em evidências reais extraídas das avaliações dos clientes.

🎯 Objetivo
Responder perguntas como:

Quais são os principais problemas relatados pelos clientes?
Por que os clientes atribuem nota 1?
Quais elogios aparecem com maior frequência?
Existe relação entre atraso na entrega e avaliações negativas?
📊 Bases Utilizadas
Customers
Orders
Order Items
Products
Payments
Reviews
Essas bases foram integradas para criar uma Knowledge Base contendo categoria do produto, nota da avaliação, sentimento, informações de entrega e comentários dos clientes.
